# AXI4-Lite Multiply-Accumulate (MAC) Unit FPGA Project

This repository contains a complete hardware/software co-design implementation of a custom **Multiply-Accumulate (MAC) Unit** packaged as an AXI4-Lite peripheral for Xilinx FPGAs[cite: 1]. The architecture handles hardware-accelerated MAC operations integrated seamlessly into a Zynq-7000 processing system block design[cite: 1].

The core hardware execution unit evaluates the following accumulation formula on each valid cycle:
Y = Y + (A * B)

Where **A** and **B** are the input operands, and **Y** is the internal tracking accumulation register initialized or maintained across successive clock cycles.

## 🛠️ System Architecture & Specifications

### Hardware Environment
* **Design Toolchain:** AMD Xilinx Vivado 2022.2[cite: 1].
* **Target Compute Platform:** Zynq-7000 Processing System (`ps7`)[cite: 1].
* **Interconnect Bus Protocol:** AXI4-Lite (Slave Interface)[cite: 1].

### Block Design Integration (`design_1`)
The custom IP block is integrated into a system-level block design layout containing the following key primitives configured in hardware:
* **Zynq Processing System (PS7):** Acts as the primary host controller running the embedded software validation stack[cite: 1].
* **AXI SmartConnect (`axi_smc`):** Handles memory-mapped transaction routing between the ARM processing cores and the custom coprocessor peripheral[cite: 1].
* **Processor System Reset Module (`rst_ps7_0_100M_0`):** Distributed synchronized hardware reset lines across the 100MHz system clock domain[cite: 1].

## 🚀 Getting Started & Workflow

### 1. Hardware Simulation & Verification
Before running full synthesis, verify register data paths using the provided SystemVerilog Bus Functional Model testbench:
1. Open the IP management development project `ip_repo/edit_mac_unit_ip_v1_0.xpr` inside Vivado[cite: 1].
2. Launch behavioral simulation using `mac_unit_ip_tb.sv` to observe read and write validation checks over the AXI master models[cite: 1].

### 2. Building the Implementation
1. Launch Vivado 2022.2 and open the main system project located in the `maac/` directory[cite: 1].
2. Generate the block design layout using the automation scripts (`design_1.bxml`)[cite: 1].
3. Create the top-level HDL wrapper (`design_1_wrapper.v`) if missing, then run **Synthesis**, **Implementation**, and **Generate Bitstream**[cite: 1].

### 3. Embedded Software Deployment
Export your hardware platform XSA into Vitis. Include the source driver components located under `ip_repo/mac_unit_ip_1_0/drivers/mac_unit_ip_v1_0/src/` into your software workspace to gain interface control primitives:
* `mac_unit_ip.h`: Contains base address definitions, command offset mapping registers, and driver execution macros[cite: 1].
* `mac_unit_ip_selftest.c`: Includes basic read/write loopback register routines to assert interface functionality directly from the embedded CPU[cite: 1].
